Interpretation
--------------
On water1/water2 v2 has high binary segmentation quality.  On water4 it is
conservative: zero false-positive pixels at 0.50, but 6,619 defect pixels are
missed (recall 0.767).  This is a calibration/domain shift, not a precision
problem.

Threshold diagnostic (not a valid selected deployment threshold)
---------------------------------------------------------------
The best Dice on each same evaluated video occurs at threshold 0.05:
water1 Dice 0.972003, water2 Dice 0.977370, water4 Dice 0.930074.  This would
raise water4 recall to 0.870574 while retaining precision 0.998305, but it is
an oracle calculation.  Select a lower operating threshold only on a separate
calibration set, not on water4 itself.
