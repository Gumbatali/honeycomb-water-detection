Input-normalization finding
---------------------------
No new normalization was mixed into this experiment.  The existing pipeline
already uses per-pixel peak normalization for the 60-frame thermal sequence,
global normalization for the seven U-Net frames, frozen U-Net BatchNorm, and
GroupNorm in the trainable spatial encoder.  Measured water1/water2 statistics
were close before the GRU: raw mean/std 0.164/0.266 versus 0.152/0.262, and
fused latent mean/std 0.445/1.083 versus 0.440/1.101.  Applying independent
normalization to every time step could erase the heating/cooling magnitude that
the recurrent layer must observe.  Recurrent normalization should be tested as
a separate controlled experiment, not combined with the augmentation result.

Final one-shot test on untouched water4
---------------------------------------
The epoch-18 checkpoint selected only on water2 was evaluated on water4 after
all training and model selection had finished.

macro IoU:   0.547147
macro Dice:  0.582354
test loss:   1.119207
ordinal MAE: 0.687684

class 1 IoU: 0.630065
class 2 IoU: 0.807531
class 3 IoU: 0.000000
class 4 IoU: 0.621600
class 5 IoU: 0.676538

The validation-to-test macro-IoU reduction is 0.045978, or 7.8% relative.
Compared with experiment 044 evaluated under the identical water4 protocol,
temporal augmentation improves test macro IoU from 0.325045 to 0.547147
(+0.222102, +68.3% relative), test loss from 1.321151 to 1.119207, and ordinal
MAE from 0.878440 to 0.687684.  The largest gain is class 5: 0.012548 to
0.676538 IoU.  Thus the validation improvement transfers strongly to the
independent recording.

Class 3 remains a systematic failure: no test pixel is predicted as class 3;
498 true class-3 pixels become background and 169 become class 4.  Experiment
044 also had zero class-3 IoU, so this failure predates temporal augmentation.
The likely issue is insufficient separation of the middle cooling curves from
one training recording, possibly compounded by class-3/4 annotation alignment.
