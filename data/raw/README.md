# Исходные данные

Термограммы `.mat`/`.7z` не хранятся в git (сотни МБ на файл).
Скачать с Яндекс.Диска:

- `4_Определение_дефектов_тепловизионного_контроля/` — 21 файл `.mat`,
  2 калибровочных (Calib Sample 1-2 Static) + 19 рабочих образцов (Sample 3-21).
- `5_Классификация_воды_и_геля/` — 4 архива `.7z` с видео экспериментов
  (образец подвешен / на полке / после переворота, 100мс, 5с нагрев, 3000 кадров),
  DOCX с методикой, архив с напечатанным образцом (4 сегмента).

Формат `.mat`: `scipy.io.loadmat(path)` →
`data: ndarray (H, W, N_frames), float32`, `FPS: float64`.

Положить скачанные файлы сюда локально — `.gitignore` их не пустит в коммит.
