# Архитектура 1: временной энкодер с физическим предобучением

Версия архитектуры, привязанная к текущему состоянию репозитория (модельная часть —
скелеты/TODO, работают только I/O и ручная нарезка по ячейкам). Опирается на
[docs/plan.md](docs/plan.md) и обосновывающую записку `podhod.md` (внешний документ),
но меняет порядок этапов: физическая синтетика идёт первой, а не последней, потому что
без неё дефицит независимых объектов (раздел «Ограничения» ниже) делает свёрточную сеть
необученной.

---

## 0. Постановка и ограничения

Объект: сотовая панель 200×200 мм, толщина 10 мм, обшивка стеклопластик 0,2 мм,
наполнитель — вощёная бумага. Шесть дефектных зон по 72 ячейки: заполнение водой
20/40/60/80/100% и одна зона с отверждённой эпоксидной смолой.

Съёмка: Optris PI 450, кадр 382×288, период кадра 100 мс, 3000 кадров, нагрев
галогенной лампой 500 Вт 5 с, односторонняя схема. NETD камеры 0,04 К.

**Ограничение, определяющее архитектуру.** Физических объектов — три, записей —
порядка шести. Для модели на изображениях один пример — один кадр с маской (выборка
порядка единиц). Пиксели коррелированы на масштабе ячейки, поэтому честная оценка
числа независимых примеров — порядка числа ячеек (сотни). Отсюда:

- полноценная сегментационная сеть, обучаемая с нуля на реальных данных, не обучаема;
- архитектура должна допускать предобучение на физически смоделированной синтетике
  и ограниченный fine-tune с малым числом размораживаемых параметров;
- пространственный контекст сети должен быть **намеренно ограничен**, чтобы сеть не
  могла заучить фиксированную раскладку зон в кадре вместо сигнала.

Тип вещества не читается по одному кадру — вода и эпоксидная смола обе выглядят
тёмными областями, различает их форма кривой остывания. Верхние уровни заполнения
(80/100%) физически вырождены: столб воды работает как полубесконечный теплоотвод,
пока тепловая волна его не прошла насквозь; расчётная разница сигналов на 30-й
секунде — около 0,03 К, что меньше NETD камеры.

1D теплопроводность по глубине слоистой структуры (обшивка → заполнитель → воздух),

Случайный разброс толщины обшивки (±10%) и мощности нагрева (±15%) в генераторе —
единственный практичный способ имитировать межобразцовый разброс без моделирования
боковой диффузии тепла, которую 1D-модель принципиально не воспроизводит.

**Явное ограничение**: 1D-модель не воспроизводит боковую диффузию, неравномерность
нагрева, разброс излучательной способности, влияние стенок сот. Численные результаты
на такой синтетике не переносятся на реальные данные напрямую — роль модели строго
ограничена предобучением энкодера на *форму* отклика, не на абсолютные значения
(см. протокол в разделе 6).

Проверка на утечку синтетики (обязательна перед использованием, раздел 8):
дискриминатор `real / synthetic` на предобученных признаках — уверенное разделение
означает артефакт, за который зацепится основная модель.

## 4. Препроцессинг

`src/preprocessing/background_subtraction.py` в текущем виде делает наивное вычитание
первого кадра. Заменяется на нормированный контраст относительно бездефектного участка
той же панели (маска — пятый слой разметки, раздел 7):

```python
def normalized_contrast(cube: np.ndarray, ref_mask: np.ndarray) -> np.ndarray:
    """C(t) = (T_ref(t) - T(t)) / (T_ref(t) - T_ref(0)).
    cube: (H, W, N_frames), ref_mask: (H, W) bool.
    Returns: (H, W, N_frames) float32.
    """
    t_ref = cube[ref_mask].mean(axis=0)
    denom = t_ref - t_ref[0]
    denom = np.where(np.abs(denom) < 1e-6, 1e-6, denom)
    return (t_ref[None, None, :] - cube) / denom[None, None, :]
```

`src/preprocessing/tsr.py` реализует собственный TODO — лог-производная как второй
канал и ресемплинг на равномерную log-сетку:

```python
def log_derivative(contrast: np.ndarray, t: np.ndarray, eps: float = 1e-3) -> np.ndarray:
    """d ln(ΔT) / d ln(t). contrast: (H, W, N_frames). Returns: (H, W, N_frames)."""

def resample_log_grid(cube: np.ndarray, t: np.ndarray, n_points: int = 64,
                       t_min: float = 0.1, t_max: float = 300.0
                       ) -> tuple[np.ndarray, np.ndarray]:
    """Ресемплинг на равномерную по log(t) сетку. Returns: (resampled (H,W,n_points), t_grid)."""
```

Итоговый вход модели — 3 канала: `[C(t), dlnΔT/dlnt, ΔT_normalized]`.

```
X: (B, 3, 64, H, W)   # batch, channels, temporal, spatial H×W
```

Хранение — float32 или ≥12 бит целочисленное. При квантовании 20 К диапазона в
8 бит шаг составляет 0,078 К — вдвое грубее NETD; разница между 80% и 100%
заполнения (~0,03 К) при этом теряется полностью.

## 6. Протокол обучения: почему архитектура не переобучается

Прямой ответ на противоречие «дефицит данных (раздел 0) vs свёрточная сеть с
десятками тысяч параметров»:

```
Этап A — предобучение на синтетике (раздел 3), 20k примеров:
    - TemporalEncoder + SpatialBlock + обе головы обучаются целиком
    - цель — форма отклика, не абсолютная температура
    - обязательна проверка на утечку синтетики (дискриминатор real/synthetic)

Этап B — fine-tune на реальных данных (water1, water4; ~280 ячеек):
    - SpatialBlock ПОЛНОСТЬЮ заморожен — он наиболее position-sensitive
      компонент и главный риск заучивания фиксированной раскладки зон
    - TemporalEncoder: разморожены только 2 последних дилатационных блока
      (dilation=4, dilation=8)
    - Головы: обучаются полностью, weight decay 1e-2, dropout 0.3
    - эффективное число обучаемых параметров при fine-tune — порядок тысяч,
      совместимо с выборкой в сотни ячеек

Этап C — оценка на water2 (полностью held-out физический объект)
```

Число обучаемых на этапе B параметров считается явно и фиксируется в отчёте
(`sum(p.numel() for n, p in model.named_parameters() if n in TRAINABLE_AT_FINETUNE)`).

## 10. Границы применимости

Решение привязано к текущему объёму данных (три физических объекта). При увеличении
числа независимых панелей до нескольких десятков полноценная сегментационная модель
по изображениям становится обучаемой и, вероятно, предпочтительной — аргументы этого
документа касаются режима малых данных, а не архитектур вообще.

Отказ от предобученных на естественных изображениях энкодеров имеет цену: их
низкоуровневые признаки могли бы быть полезны и на термограммах. Подход, основанный
на временных профилях, этой возможностью не пользуется.

Разделимость уровней 80% и 100% подлежит измерению, а не предположению (раздел 8).
Терминологическая неопределённость «гель» vs «эпоксидная смола» в исходных данных
требует уточнения до финальной разметки — если это разные вещества, число классов
`ClassificationHead` увеличивается до 4.
