# Honeycomb Water/Gel Detection

Автоматизированная детекция, локализация и классификация влаги и геля в сотовых
композитных конструкциях по данным активного теплового контроля (ИК-термография),
с аугментацией и синтезом обучающих данных.

## Задача

На основе методики активного теплового контроля (см. [docs/references.md](docs/references.md))
решаются три связанные подзадачи:

1. **Детекция** — есть ли дефект (вода/гель/эпоксидка) в контролируемой зоне.
2. **Локализация** — где именно на термограмме находится дефектная зона
   (сегментация по ячейкам сот / bounding box).
3. **Классификация** — тип вещества и степень заполнения ячейки
   (0/20/40/60/80/100% воды, гель, эпоксидная смола, норма).

Дополнительно:

- **Аугментация** данных термограмм (пространственная, временная, радиометрическая)
  с учётом симметрии сотовой решётки и физики теплового процесса.
- **Синтез** данных на основе физической модели теплопередачи для промежуточных
  уровней заполнения, которых нет в реальных экспериментах.

## Архитектура

Три физических объекта и порядка шести записей — недостаточно для обучения
полноценной сегментационной сети с нуля на реальных данных. Подход: временной
энкодер (Conv3d по оси времени, общие веса по пикселям) с пространственно
ограниченным рецептивным полем (~1.4 ячейки, чтобы не заучить фиксированную
раскладку зон в кадре), предобученный на физически смоделированной синтетике
и дообученный на реальных данных с частичной заморозкой весов. Две раздельные
головы — классификация вещества и порядковая (CORAL) регрессия количества воды,
не единая числовая шкала, так как эффузивность отверждённой эпоксидной смолы
близка к эффузивности стеклопластиковой обшивки, а не воды.

Полное описание, обоснование каждого решения и то, что переиспользуется из
текущего кода против того, что пишется заново — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Структура репозитория

```
data/
  raw/           # исходные .mat/.7z термограммы (не хранятся в git, см. data/raw/README.md)
  processed/     # предобработанные данные (фон вычтен, TSR, ресемплинг)
  synthetic/     # синтетические/аугментированные данные
docs/
  references.md  # обзор источников и связанных публикаций
  data_catalog.md# каталог образцов: ориентация, вещество, % заполнения, разрешение
notebooks/        # исследовательские Jupyter-ноутбуки
src/
  preprocessing/  # вычитание фона, TSR, ресемплинг, нормализация
  detection/      # детекция/сегментация дефектных зон
  classification/ # классификация типа вещества и % заполнения
  augmentation/   # аугментация термограмм
  synthesis/      # физическая модель теплопередачи, генерация синтетики
  utils/          # загрузка .mat, визуализация, метрики
tests/            # unit-тесты
scripts/          # CLI-скрипты запуска пайплайна
```

## Данные

Исходные термограммы (`.mat`, `.7z`) не хранятся в репозитории из-за размера
(сотни МБ на файл). Файлы лежат на Яндекс.Диске, см. [docs/data_catalog.md](docs/data_catalog.md)
для описания структуры данных и ссылок.

Формат `.mat`: массив `data` формы `(H, W, N_frames)` типа `float32`
(термограммы в градусах/relative units) + скаляр `FPS`.
