# План работ

## Этап 0 — Инвентаризация данных
- Каталогизировать все `.mat` (`scripts/catalog_data.py`).
- Определить, где есть разметка зон, где только сырые кадры.

## Этап 1 — Предобработка
- Вычитание фонового кадра (baseline, как в источнике).
- TSR как альтернативный вариант — сравнить устойчивость при разных условиях.
- Ресемплинг разрешения/FPS к общему формату.

## Этап 2 — Детекция и локализация
- Baseline: пороговая сегментация по амплитуде разностного кадра.
- ML: сегментационная сеть (U-Net) поверх карт признаков термограммы.

## Этап 3 — Классификация
- Baseline: воспроизвести 5-слойный MLP на температурных профилях (как в источнике).
- Развитие: 1D-CNN/LSTM по временному профилю или 3D-CNN по кубу термограмм.
- Классы: {норма, вода-20/40/60/80/100%, гель-*, эпоксидка}.

## Этап 4 — Аугментация
- Пространственная: повороты на 60°/120°, отражения (симметрия сот), сдвиги/кроп.
- Временная: интерполяция/обрезка по кадрам.
- Радиометрическая: вариация амплитуды нагрева, шум по калибровочным Static-съёмкам.

## Этап 5 — Синтез данных
- Физическая модель теплопередачи ячейки (обшивка + вещество-заполнитель).
- Генерация синтетических профилей для промежуточных % заполнения.
- Валидация синтетики по шумовой модели сенсора (из Calib Sample *.mat).

## Этап 6 — Обучение и оценка
- Split train/val/test по образцам (не по кадрам — избежать утечки).
- Метрики: IoU/mAP (детекция), accuracy/F1 (классификация), MAE (% заполнения).
- Ablation: baseline vs +аугментация vs +аугментация+синтетика.
