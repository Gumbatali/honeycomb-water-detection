## Ключевые методические решения источника 1 и внутреннего отчёта

- Предобработка: вычитание первого (фонового) кадра — предпочтено методу TSR
  из-за риска переобучения сети на конкретные профили при изменении условий эксперимента.
- Обучающие точки: для каждой дефектной зоны — 5 областей (4 угла + центр),
  температурные профили этих областей используются как отдельные примеры.
- Целевые значения при обучении: 1.0 (100% воды) ... 0.2 (20% воды), 1.2 (эпоксидная смола).
- Разбиение на схемы контроля: "снизу" (вода касается обшивки) vs "сверху"
  (вода отделена воздушным зазором) — точность различается по зонам.
